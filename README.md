# Lifeboard

A boxy, whiteboard-style life dashboard. Static site, no build step, no server.

- **Views:** Board · Today · Kanban · Matrix · List · Habits · Training · Wins
- **Theme kinds:** Tasks (one-off), Daily (streaks), Progress (logged numbers + chart)
- **Data:** lives in your browser (localStorage). Optional sync to a *secret* GitHub Gist (Sync & backup).
- **Shortcuts:** press `?` in the app.

Run locally: `python3 -m http.server` then open http://localhost:8000. Tests: `npm test`.
